# 后端审查与修正记录

审查范围：API、上下文、监控、主 Agent、子助手、全部工具、文件路径、Word 转换、配置与依赖。未审查虚拟环境第三方源代码；仅核对使用到的 SDK 行为。

## 已落实

| 问题 | 修正 |
| --- | --- |
| 上传拼接任意路径且无大小限制 | UUID 会话、文件名验证、允许扩展名、分块写入、20 MiB 限制、重名后缀 |
| Agent 路径可逃出会话目录 | resolve 后验证目录归属，拒绝 ../ 和链接逃逸，兼容会话路径前缀 |
| 只有 started，没有可恢复的任务终态 | run_id、SQLite 任务/事件/结果、状态查询、启动时标记中断 |
| 相同会话并行调用模型 | 后端活动任务检查，返回 409；前端同步禁用提交 |
| WebSocket 被新连接覆盖，旧断开删除新连接 | 每会话连接集合、逐连接锁和失败清理 |
| 连接前或断线时事件丢失 | ready 握手后提交，状态快照补齐事件，序号去重 |
| 任务准备失败不通知用户 | 准备操作置于 API 任务异常边界，确保失败终态 |
| 每轮重新复制资料可能覆盖报告 | 上传直接进入会话目录，旧资料只在目标不存在时导入 |
| 文档生成提示词引用不存在的助手 | 改为主 Agent 直接调用文件工具 |
| 无配置工具仍导入/注册 | 按配置标记注册助手，health 只报告是否配置 |
| SELECT 前缀检查不足，表名可注入 | SQL AST 只读检查、表白名单、结果上限、只读事务和超时；仍要求 SELECT-only 账号 |
| RAG 会话异常时不释放 | finally 清理及空助手处理；累计内容使用最后快照 |
| 文件接口暴露机器绝对路径 | 使用 UUID 会话和相对 storagePath |
| 通配 CORS 与个人本地边界不一致 | 限制本地来源及 WebSocket Origin，启动默认回环监听 |

## 保留的首版限制

- 无账号与权限系统，面向个人本机，不应直接绑定公网地址。
- 模型记忆仍在 InMemorySaver 中。前端以服务实例标识检测重启并提示新建会话。
- PDF 依赖 Windows Word COM。没有 Word 时会明确失败，可继续下载 Markdown。
- TXT/PDF 等大文档仍可能产生较大模型上下文；20 MiB 上传限制不等于 token 预算控制。
- SQL AST 和只读事务应与数据库 SELECT-only 权限组合，代码不自动调整外部数据库授权。
- 自动测试使用桩验证本地协议，实际搜索、MySQL、RAG 和 Word 是否可用取决于本机配置。

## 验证

测试涵盖任务重复提交及单一终态、失败信息脱敏、上传/下载/越界/超限、多连接、状态持久化及重启中断、SQL 拒绝规则。前端验证类型检查、lint、单元测试、安全 Markdown 和浏览器主流程。

完成结果：后端 8 项 unittest 通过；前端 4 项 Vitest 通过；4 项 Playwright 通过（上传/提问/下载/刷新历史、失败恢复、运行中刷新且 WebSocket 不可用时结果补齐且不重复提交、移动端抽屉）；生产构建与 ESLint 通过。已检查桌面欢迎页、结果页和移动端截图。真实 Agent 装配通过，未调用收费模型或远端数据库进行验收。

## 2026-10-17 稳定性补充

- `python api/server.py` 不再默认启用 Uvicorn reload，热重载改为显式选择。
- 增加后台任务完成回调，读取并记录遗漏异常，避免静默的 event-loop 错误。
- health 增加 PID、UTC 启动时间和运行时长，便于确认服务是否重启。
- 新增 `scripts/start-backend.ps1`，统一工作目录、虚拟环境、日志和可选热重载参数。
- Python faulthandler 与生命周期日志用于区分业务失败、正常关闭和进程级中断。
- 后端测试扩充到 11 项并全部通过；新版本在临时端口完成真实 Uvicorn 单进程冒烟测试。
- 根据 faulthandler 捕获的 Windows `access violation`，MySQL Connector 改为 `use_pure=True`；避免 `connection_cext.py` 原生崩溃绕过 Python 异常边界并终止 Uvicorn。
